# BiechuUnitFrames 别处头像框体

一款基于《魔兽世界》巫妖王之怒（3.3.5 WLK）暴雪原生头像框体深度增强的插件。不替换原有框体，而是在原生框体上叠加大量实用功能与自定义选项，轻量、稳定、开箱即用。

- **适用版本**：3.3.5 WotLK（已适配 Whitemane / Frostmourne、Stormforge 等私服）
- **插件版本**：3.3.5_WLK_1.4
- **作者**：starpt
- **语言**：简体中文 / English / Русский（自动跟随客户端语言）
- **命令**：`/bc` 打开设置（也可通过 ESC → 界面设置 → 插件 → BiechuUnitFrames）

## 功能总览

### 框体布局

```
├ 玩家 ├ 宠物         ├─ 宠物的目标
├ 目标 ├─ 目标的目标   ├ 焦点 ├─ 焦点的目标
└ 队友 ├─ 队友的宠物   └─ 队友的目标 (×4)
```

所有主要框体均支持**非战斗状态下按住 Shift 自由拖动**（可分别开关），并支持整体缩放。

### 全局设置

- **暗黑主题**：一键切换全套暗黑材质（边框、状态条、PVP 图标、威胁边框等）
- **新风格职业图标**：头像 / 小图标可选新绘制的职业图标
- **体力条颜色按生命值百分比渐变**（绿 → 红）
- **玩家名字职业着色**
- **数值单位进位**：万/亿 或 K/M 两种显示方式
- **显示预治疗**：基于内置 LibHealComm-4.0，显示即将受到的治疗量
- **PVP 自动 TAB**：竞技场 / 战场中 TAB 键自动只选择敌方玩家
- **进入达拉然自动关闭姓名板**，离开自动恢复
- **自由拖动系统框体**：任务、对话、商人、角色信息、天赋、宏、按键设置、社交、成就、地下城查找器等几乎所有系统窗口都可拖动归位
- **禁用冲突插件**：进入游戏自动检测并禁用 DuowanMove、EN_UnitFrames、TUnitFrame、BUnitFrame、PorEnhance 等功能冲突的插件
- **装备对比**开关（等同暴雪"始终比较装备"）
- 名字 / 数值字体、字号、轮廓（无 / 细边 / 粗边 / 锐利）自由选择
- **配置方案**：支持"账号通用"与按角色独立保存，一键重置

### 玩家框体

- 战斗中边框发红光提醒
- **德鲁伊专属法力条**：变熊 / 变猫等形态下额外显示蓝条（替代原生能量条位置，可开关）
- **法力条 5 秒回蓝指示**：施法消耗法力后显示倒计时闪动光标（德鲁伊三条均支持，且正确处理生命分流等特殊技能）
- 边框风格可选：普通 / 稀有 / 稀有精英 / 精英
- 头像可选：默认 3D 头像、职业图标、猫猫、狗狗、熊猫、咕有云、酷脸等趣味头像
- **天赋小图标**：
  - 悬停显示当前天赋构成（如 51/20/0）
  - 左键点击在主 / 副天赋间切换
  - 开启"切换天赋后装备天赋名套装"后，切天赋自动换装
  - Shift + 点击一键脱装（方便换血色 / 交任务装等）
- **装备套装小图标**：显示最多 6 个套装图标，点击一键换装，Shift + 点击保存套装，当前已装备套装高亮
- 在团队中隐藏小队编号

### 宠物 / 宠物的目标

- 宠物框体可拖动（默认跟随玩家框体）
- 宠物的目标框体可显示 / 隐藏（默认隐藏），可缩放
- 均可隐藏名字，带独立血量 / 蓝量显示

### 目标 / 焦点框体

- **小图标**：玩家显示职业图标、NPC 显示生物种类图标（野兽 / 人型 / 龙 / 亡灵 等），悬停查看提示，点击有快捷操作：
  - **Alt + 点击**：邀请加入队伍（支持不同阵营）
  - **Ctrl + 点击**：请求交易（支持不同阵营）
  - **Shift + 点击**：复制名字
  - **鼠标左键**：观察目标
  - **鼠标中键**：密语对方
  - **鼠标右键**：跟随目标
- **Buff/Debuff 智能显示**：
  - 只显示自己（或宠物 / 载具）施放的 Buff/Debuff 的倒计时（需 OmniCC）
  - 只显示可以驱散的 Debuff / 可以偷取的 Buff 的倒计时
  - **高亮可驱散 / 可偷取的魔法**（发光描边）
  - 其他人施放的 Buff/Debuff 按百分比缩小显示，一眼区分
  - 图标大小、每行数量、行列间距、坐标完全可调
- 数值威胁值指示（可居左显示），自动按稀有 / 精英切换边框
- 手动关闭 PVP 后图标显示 5 分钟倒计时
- 目标 / 焦点与玩家框体水平居中对齐，可一键恢复默认位置
- 鼠标悬停血条 / 蓝条时显示额外数值（配合侧边数值样式）
- 兼容 Quartz 施法条自动定位

### 目标的目标 / 焦点的目标

- 可显示 / 隐藏，超出范围半透明
- 可拖动（默认关闭），可隐藏名字

### 队友框体

- 团队中可继续显示小队框体，也可整体隐藏
- 显示队友等级
- **显示队友施法条**（含施法图标，不可打断时显示护盾边框）
- **超出施法范围半透明**（按职业法术智能判断距离）
- 头像显示战斗信息（伤害 / 治疗数字飘字）
- **Buff/Debuff 智能过滤**（同目标框体：只显示自己施放的 Buff、只显示可驱散的 Debuff 及倒计时）
- 队友的宠物 / 队友的目标均可显示 / 隐藏、隐藏名字
- 战斗中边框红光提醒

## 数据保存

保存于 `WTF\Account\...\SavedVariables\BiechuUnitFramesDB`。玩家 / 目标框体位置同时记录在 `layout-local.txt` 中。

## 依赖

- 无必须依赖（LibHealComm-4.0 已内置）
- 可选插件：**OmniCC**（Buff/Debuff 倒计时数字）、**Quartz**（施法条联动定位）

## 目录结构

```
BiechuUnitFrames/
├── BiechuUnitFrames.toc    # 插件描述文件
├── Global.lua              # 核心：默认设置、Buff/Debuff、小图标、暗黑主题、预治疗、系统框体拖动等
├── Player.lua              # 玩家 / 宠物 / 宠物目标：天赋图标、套装图标、德鲁伊法力条、5秒回蓝等

```

## 常见问题

- **Q：为什么战斗中不能拖动 / 改设置？**
  A：暴雪在战斗中禁止部分界面操作，插件会在团队警告框架提示"战斗中无法更改设置!"，脱战后再操作即可。

- **Q：Buff 图标不显示倒计时数字？**
  A：安装 OmniCC 插件即可。

- **Q：位置拖乱了怎么恢复？**
  A：设置界面中提供"恢复默认位置 / 恢复左上角位置 / 恢复水平居中位置 / 和玩家框体对齐"等一键归位选项，也可整体重置。
